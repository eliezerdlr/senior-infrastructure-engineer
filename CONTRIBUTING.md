# Contributing

1. Keep each change scoped and evidence-based.
2. Preserve upstream licences, notices, provenance, and trademarks.
3. Do not add credentials, customer inventories, private endpoints, production logs, or personal data.
4. Default operational guidance to read-only discovery.
5. Gate privileged, disruptive, destructive, costly, or externally visible actions with explicit authorization, rollback, and validation.
6. Add or update tests for manifest, routing, metadata, or security behavior.
7. Run `npm run validate` before opening a pull request.

New specialists must have a unique name, a clear use condition, an explicit licence, provenance, bounded operational behavior, and an entry in the routing and third-party notices.
