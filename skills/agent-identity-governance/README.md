# Agent Identity Governance

Local, instruction-only skill for governing AI agent and other non-human identities across creation, authorization, monitoring, access review, incident response and retirement.

It adds no executable code, dependency, directory connector, credential reader or tenant mutation. The main package glob discovers it automatically. Use `SKILL.md` for the workflow and `references/` for the control matrix and Microsoft Entra/AD boundary.
