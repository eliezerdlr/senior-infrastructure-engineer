# controlled-technical-english

A local controlled-language profile for clear technical writing. It is complete for its stated workflow and has no runtime or network dependency.

The profile is adapted from general principles in a Paperclip AI `simplified-english` skill. It intentionally removes the original formal compliance claim because the complete ASD-STE100 controlled dictionary and an approved validation process are not bundled.
